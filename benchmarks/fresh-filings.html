How it works

Four steps, the same every week

  1. Take the week's annual reports

    The SEC's daily index lists every 10-K, 20-F and 40-F filed that week; amendments are left out.

  2. Ask what only they can answer

    Each question needs a figure the company reported for the first time that week: a lookup, a change from the year before, a ratio or assets minus liabilities.

  3. Ask the same model twice

    Once on its own, once with canli-mcp. Same prompt, same limits, run on the open-source eval.mjs.

  4. Check every answer against the filing

    An independent checker recomputes each answer from the SEC's data; nothing is tuned on the week's questions.

Questions

About the test

Why use filings from last week?

A model learns from text written before its training ended. Figures a company first reported last week cannot be in that text, so the model either reads the filing or does not know. That separates an assistant that looks things up from one that recalls or guesses.

Who writes the questions?

A program, the same every week: weekly.mjs reads the SEC's list of annual reports filed that week and asks about figures each report gives for the first time. Nobody picks questions a tool is good at.

How is an answer marked right?

It has to match the figure in the filing: a dollar amount within a tenth of a percent, a percentage within five hundredths of a point, a ratio within five ten-thousandths. Saying "not reported" is never right here, because every question has an answer in the filing.

Is this a fair test of other tools?

This page compares one model alone and with canli-mcp, which we build, so weigh that. Every question, answer and run is downloadable below, so anyone can run another tool on the same questions.

Limits: one model and one run a week; questions come from a fixed set of templates over figures companies tag in their filings; a company's earnings release can give a figure some days before its annual report. Not investment advice.
