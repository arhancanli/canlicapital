Benchmark, interim result of 2026-10-09

Finance MCP servers, head to head

By Arhan Canli, Canli Capital

On the 14 questions every server finished, canli-mcp answered 79% correctly (22 of 28 runs). The best of the other servers, EdgarTools + Yahoo Finance MCP, answered 54% (15 of 28).

Every server got the same model (gpt-5.4-mini), system prompt, 12-turn limit, 30,000-character cap on each tool result and scoring. Only the MCP server changed. No server had an API key. Each question ran 2 times per server, and the answers were computed from primary sources (SEC EDGAR, the US Treasury, FRED and Yahoo Finance chart data) separately from every server compared.

Read this before quoting it

  • We wrote the 24 questions, in seven categories our servers were built for. What the other servers do well beyond them is not scored: news, options chains and analyst ratings (Yahoo Finance MCP), statement comparisons from XBRL (EdgarTools) and the many keyed data sources OpenBB connects to.
  • The fair comparison is the first canli-mcp column. The two later columns are the same server after fixes this benchmark prompted, so they were tuned on these questions. A held-out set of 24 new questions, written after the fixes, will test the fixed server; it waits for API credit.
  • The API account ran out of credit during the runs. OpenBB finished 14 of the 24 questions and EdgarTools 20. Runs stopped by the account are left out, never scored as wrong, and the headline compares only the 14 questions every server finished.
  • One model and two runs per question. A difference of a question or two is noise.
  • Before scoring, we widened the 10-year yield tolerance to accept a market close instead of only Treasury's official rate, and checked that EdgarTools' wrong filing answers came from its own responses, not from the 30,000-character result cap.
