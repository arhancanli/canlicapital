canli-mcp: every finance tool an agent needs, behind three

canli-mcp is one open-source MCP server for SEC filings, company fundamentals, Treasury and FRED data, prices, quant analytics, backtest validation and paper trading: 285 tools behind 3. The model sees 3 tools; the rest wait behind them.

How an agent uses it

Three tools in front of 285

The model is shown three tools instead of hundreds. It searches for the one it needs, reads that tool's arguments and runs it, and the rest never enter its context.

  1. find_toolsearches every tool by what you ask for
  2. describe_toolreads one tool's arguments
  3. run_toolruns any tool, or up to 25 in one round trip
  • 47 in 50times the right tool came first when asked for in plain words; in the top three, 50 in 50
  • 23 tokensto pass 1,000 prices as a file, instead of 4,893 pasted, and no number can be dropped on the way
  • 72 tokensof tool input to label 1,000 prices and weight the labels in one round trip, against 31,917 when the model copies the labels across

Install

Add it in one line

Free and MIT-licensed. It needs Node.js 20.10 or later and no account; the quant and validation tools run on your machine.

canli-mcp is being published to npm now, so these lines will work once it is. Until then each server it combines installs on its own:

  • claude mcp add canli-quant -- npx -y canli-quant-mcpQuant finance, 0.1.0 on npm
  • claude mcp add canli-validation -- npx -y canli-validation-mcpBacktest validation, 0.14.0 on npm

Using them together

Start with research to see what has been tried and what failed. Use fundamentals to rebuild what a company had reported by your decision date. Once you have built a strategy's returns, with your own care for costs and look-ahead, use validation to check whether the result could be luck.

Each answers a different question. Accounting numbers are not returns, a paper can describe a failed test, and no statistic promises future profit.

Source data, datasets and reproduction

  • SEC company reference and source filings
  • FilingFacts dataset: financial questions with source evidence
  • FilingFacts review and annotation workspace
  • Null Zoo research benchmark
  • Open paper evidence reporting standard
  • ALPHAC, point-in-time lake and backtester repositories

FilingFacts v0 is machine-checked; its review packet does not establish independently adjudicated human gold. The paper evidence standard is a proposal with disclosed implementation and review limits.

Versions, privacy and trading

The hosted servers run the released version shown on each card; npm can lag behind it for a short while. Read the setup guide before sending private strategy data anywhere.

The research and fundamentals servers read public records only. Hosted validation stores a signed receipt of each check under the free-key quotas; the npm server in local mode keeps your returns on your machine. A separate, unreleased local paper-trading workflow handles position sizing, pre-trade checks and signed trade journals. It connects to no broker. The execution-cost calculator is available in the browser. Download the discovery record with the hosted release pins and examples.
