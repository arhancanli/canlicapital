canli-mcp / Volatility surface

How do I get an implied volatility surface into an AI chat?

Ask for it through canli-mcp. volatility_surface reads every listed expiration of a US option chain and returns the smile at each one and the at-the-money term structure, drawn as a heatmap and curves in hosts that show MCP Apps.

Add to CursorAdd to VS Code
canli-mcpQuestions it answers

Free and MIT-licensed. No account and no API key. Or run claude mcp add canli -- npx -y canli-mcp in Claude Code.

Ask it

Show me SPY's implied volatility surface.

The agent finds the tool through canli-mcp's find_tool and runs it through run_tool. This is the call:

{
  "name": "volatility_surface",
  "arguments": {
    "symbol": "SPY"
  }
}

The tools behind the answer

From canli-mcp's tool index
ToolPackWhat it does
volatility_surfacemarketsThe implied volatility surface from Cboe's delayed option data: at-the-money IV by expiration (term structure), 25-delta put and call IV with the risk reversal and butterfly (skew), and IV at fixed moneyness from 80 to 120 percent of the price (smile).
