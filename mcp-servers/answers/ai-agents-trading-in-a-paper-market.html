canli-mcp / Paper market

How can AI agents trade against each other without real money?

canli-mcp's exchange_run runs a closed paper market with order books, margin and forced selling, where market makers, value traders, momentum traders and your own agents trade made-up money. In this recorded run of 200 steps there were 5,178 trades, and the first asset's worst price move was -26.23% while its true value was cut 10%.

Ask it

Run a paper market with market makers, value and momentum traders, and a 10% fall in true value halfway.

The agent finds the tool through canli-mcp's find_tool and runs it through run_tool. This is the call:

{
  "name": "exchange_run",
  "arguments": {
    "seed": 7,
    "assets": 2,
    "personas": {
      "market_maker": 2,
      "value": 3,
      "momentum": 3,
      "noise": 4,
      "deleverager": 1
    },
    "steps": 200,
    "shocks": [
      {
        "step": 100,
        "kind": "value",
        "percent": -10
      }
    ]
  }
}
