canli-mcp / Stock screens

Can an AI agent screen stocks by fundamentals?

Yes. canli-mcp's screen_companies tool screens every US-listed company on figures from their filings, such as revenue growth, margins or valuation, and sorts the result.

Add to CursorAdd to VS Code
canli-mcpQuestions it answers

Free and MIT-licensed. No account and no API key. Or run claude mcp add canli -- npx -y canli-mcp in Claude Code.

Ask it

Which US companies have more than $100 billion in revenue?

The agent finds the tool through canli-mcp's find_tool and runs it through run_tool. This is the call:

{
  "name": "screen_companies",
  "arguments": {
    "filters": [
      {
        "metric": "revenue",
        "op": ">",
        "value": 100000000000
      }
    ],
    "sort_by": "revenue",
    "limit": 10
  }
}

The tools behind the answer

From canli-mcp's tool index
ToolPackWhat it does
screen_companiesmarketsScreen every US-listed company (thousands, from SEC XBRL frames) on fundamentals: revenue, growth, margins, ROE, ROA, free cash flow, R&D intensity, leverage and more, for a calendar year or each company's fiscal year ending in a date window, with filters, ranking and optional valuation (price, market cap, P/E, P/S, FCF yield). Implausible figures (tagging slips) are held out and listed apart.
