canli-mcp / Options chains

Is there an MCP server for options chains?

Yes. canli-mcp's options_chain tool returns calls and puts for a US stock or ETF with bid, ask, volume, open interest and implied volatility, for any listed expiration, with no API key. volatility_surface puts the whole chain on one surface.

Add to CursorAdd to VS Code
canli-mcpQuestions it answers

Free and MIT-licensed. No account and no API key. Or run claude mcp add canli -- npx -y canli-mcp in Claude Code.

Ask it

Show me SPY's nearest option chain around the money.

The agent finds the tool through canli-mcp's find_tool and runs it through run_tool. This is the call:

{
  "name": "options_chain",
  "arguments": {
    "symbol": "SPY",
    "window": 0.03,
    "type": "both"
  }
}

The tools behind the answer

From canli-mcp's tool index
ToolPackWhat it does
options_chainmarketsAn option chain from Cboe's delayed data for a stock, ETF or index (AAPL, SPY, SPX, VIX): bids, asks, implied volatility, greeks, open interest and volume by strike for one expiration, every expiration with its open interest, put/call ratios, max pain and the move the at-the-money straddle prices in.
volatility_surfacemarketsThe implied volatility surface from Cboe's delayed option data: at-the-money IV by expiration (term structure), 25-delta put and call IV with the risk reversal and butterfly (skew), and IV at fixed moneyness from 80 to 120 percent of the price (smile).
