canli-mcp / 13F holdings

How can an AI agent read a hedge fund's 13F holdings?

Ask canli-mcp's fund_holdings tool for the manager. It reads the 13F filings on SEC EDGAR, lists the top positions with value and share counts, and can compare a quarter with the one before to show what was bought and sold.

Add to CursorAdd to VS Code
canli-mcpQuestions it answers

Free and MIT-licensed. No account and no API key. Or run claude mcp add canli -- npx -y canli-mcp in Claude Code.

Ask it

What does Berkshire Hathaway hold, and what changed last quarter?

The agent finds the tool through canli-mcp's find_tool and runs it through run_tool. This is the call:

{
  "name": "fund_holdings",
  "arguments": {
    "manager": "Berkshire Hathaway",
    "top": 10,
    "compare": true
  }
}
