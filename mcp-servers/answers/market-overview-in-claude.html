canli-mcp / Market overview

How do I get today's market overview in an AI chat?

Ask for it with canli-mcp's market_overview tool. It returns the main US and world indexes, rates, commodities, currencies and crypto with the day's moves, as a market map whose tiles open their charts in hosts that draw MCP Apps.

Add to CursorAdd to VS Code
canli-mcpQuestions it answers

Free and MIT-licensed. No account and no API key. Or run claude mcp add canli -- npx -y canli-mcp in Claude Code.

Ask it

How are markets doing today?

The agent finds the tool through canli-mcp's find_tool and runs it through run_tool. This is the call:

{
  "name": "market_overview",
  "arguments": {}
}
