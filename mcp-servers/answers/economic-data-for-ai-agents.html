canli-mcp / Economic data

How can an AI agent get economic data like inflation and unemployment?

canli-mcp's economic_series tool reads official statistics such as CPI, unemployment and GDP at the source, with year-on-year and other changes computed for you. economic_calendar lists the releases coming up and world_economy covers other countries.

Add to CursorAdd to VS Code
canli-mcpQuestions it answers

Free and MIT-licensed. No account and no API key. Or run claude mcp add canli -- npx -y canli-mcp in Claude Code.

Ask it

What has US inflation been over the last year?

The agent finds the tool through canli-mcp's find_tool and runs it through run_tool. This is the call:

{
  "name": "economic_series",
  "arguments": {
    "series": "CPIAUCSL",
    "transform": "yoy",
    "last": 12
  }
}

The tools behind the answer

From canli-mcp's tool index
ToolPackWhat it does
economic_seriesmarketsAny FRED economic series (inflation, unemployment, GDP, payrolls, rates, credit spreads, oil, FX, money supply, recession indicators) by id or plain words, as dates and values, optionally as changes or year-over-year rates. Feed values straight into analysis tools.
economic_calendarmarketsThe US economic calendar from the agencies' own schedules: when BLS (jobs, CPI, PPI, JOLTS), BEA (GDP, personal income and PCE, trade), the Census Bureau (retail sales, housing starts, durable goods) and the Fed (FOMC decisions) release, with times in US Eastern and the market-moving releases flagged.
world_economymarketsAny country's or region's economy from the World Bank's World Development Indicators (200+ countries, the euro area, the world, income groups): GDP and growth, inflation, unemployment, government debt and deficits, the current account, trade, reserves, interest rates, population and more, by plain words or indicator code, as a year-by-country table with each country's latest value.
