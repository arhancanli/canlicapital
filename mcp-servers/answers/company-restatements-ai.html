canli-mcp / Restatements

Which figures did a company restate after first reporting them?

canli-mcp's restatements tool compares what a company first reported with what its latest filing says, free with no key. For Becton Dickinson it scanned 4,329 annual values and 661 had changed. A change can be a restatement, a reclassification or a correction, so read the filing it names before calling it an error.

Ask it

Which of Becton Dickinson's annual figures changed after they were first reported?

The agent finds the tool through canli-mcp's find_tool and runs it through run_tool. This is the call:

{
  "name": "restatements",
  "arguments": {
    "company": "BDX",
    "periods": "annual",
    "limit": 10
  }
}
