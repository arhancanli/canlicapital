When to use this server

Use this server to inspect the research record behind ALPHAC. Search paper titles and summaries, browse topic indexes, and read a paper or one section without sending the entire library to an assistant. The trial ledger provides search context; the paper record and verification-chain head provide the current published evidence.

Connect the hosted server

Paste this URL into a client that supports MCP over Streamable HTTP:

https://canlicapital.com/mcp/research

For Claude Code, register the same endpoint:

claude mcp add --transport http canli-research https://canlicapital.com/mcp/research

The tool list below describes hosted version 0.2.0. The canli-research-mcp npm package can have a different version; check its published version and README before using a local install. The developer setup guide covers clients, API keys and local validation.

A useful first workflow

  1. Search by a mechanism or browse list_topics. Include feasibility work and killed candidates when checking how a mechanism was investigated.
  2. Read the returned paper slug with get_paper. Request a section and set max_chars when you need a bounded excerpt; follow the paper's own sources and limitations.
  3. Check trial_ledger before interpreting a result, then inspect live_record and chain_head. Distinguish current paper observations from mature, funded or independently reviewed performance.

Example tool arguments

Find up to five published papers matching momentum, then read a returned slug with get_paper. Search results reflect this project's research record, not the entire academic literature.

{
  "name": "search_research",
  "arguments": {
    "query": "momentum",
    "limit": 5
  }
}

This is a tool name and arguments for your MCP client, not an HTTP request to paste into the endpoint.

Tools in the hosted release

canli-research-mcp 0.2.0 tool reference
ToolPurpose and input scope
search_researchFind Canli Capital research papers (strategy tests, killed candidates, literature reviews, feasibility protocols) by words in their titles and summaries. Use it to find a paper's slug, then read it with get_paper; to browse by subject instead, use list_topics.
list_topicsThe research topics, with how many papers each holds and what it covers.
get_paperA research paper's text as published, by slug, with its headings; send section for one part, and max_chars to cap the length. Find the slug with search_research or list_topics first.
trial_ledgerHow many distinct hypotheses Canli Capital has tried against its declared budget, and how many were killed or survived. Use it to judge any published result against the size of the search behind it.
live_recordThe live paper-trading record (returns, costs, risk, corrections, provenance) and each sleeve's paper equity, with their limits. Use it for how the strategies are doing now; for why they exist, read the papers.
chain_headThe head of the tamper-evident chain that shows the published record was not rewritten after publication, with where to verify it. Use it to check that a figure you read was not changed later.

Evidence limits

The server reads public Canli Capital documents and caches them for the session. A paper can describe a failed, corrected or incomplete investigation. Paper execution does not establish funded results. A tamper-evident publication chain does not establish completeness of the research search or independent review.
