canli-mcp / Quant finance

Graham number and growth formula

Compute Benjamin Graham's number (sqrt 22.5 x EPS x book value per share) and his revised growth formula value, with margin of safety against a price.

canli-mcpInstallEvery toolHow it worksQuestions it answers

The tool is graham_valuation in canli-mcp 0.22.0, free and MIT-licensed, with no account and no API key. It comes from canli-quant-mcp, which canli-mcp includes, and it is also its own server.

How a model reaches it

Ask in plain words. The model finds graham_valuation with canli-mcp's find_tool, reads its arguments with describe_tool if it needs to, and runs it with run_tool. The call has this shape, with your values in place of the angle brackets:

{
  "name": "graham_valuation",
  "arguments": {
    "eps": "<number>"
  }
}

Words that find it

Besides its name, title and description, find_tool matches a question to graham_valuation on these words: graham, number, intrinsic, value, benjamin, growth, formula, margin, of, safety, investing.
