00Canli Capital

Finance runs on numbers. Left alone, AI models make them up.

Canli Capital is an open-source lab that connects AI agents to financial data and quant tools they can check. Its flagship MCP server, canli-mcp, reads SEC filings, Treasury and FRED data at the source and puts 285 finance tools behind three. The code is free and MIT-licensed.

01The problem

Ask a model for a company's numbers, and it guesses.

We asked AI models 150 questions about what companies reported to the SEC, with no tools. GPT-5.4 mini gave 84 numbers. 96% of them were wrong.

The wrong numbers read exactly like right ones. Nothing in the answer tells you which is which.

  • 84numbers given
  • 96%of them wrong
  • 150questions

FilingFacts, our open benchmark of SEC filing questions

02The tools

The open tools hand the model a haystack.

OpenBB's MCP server lists 1,056 tools. Sent in full, they cost 432,001 tokens on every request, before the model reads the question.

And in our benchmark, every other server missed at least one kind of question entirely: SEC filings, rates and macro, prices or analytics.

  • 1,056tools in one list
  • 432,001tokens per request
  • 4 of 4left a kind of question at zero

03The solution

One server between the model and the market.

canli-mcp shows the model 3 tools and keeps 285 behind them. The model searches for what it needs, reads that tool's arguments and runs it. The data comes from where it was first published: SEC filings, the Treasury's yield curve and FRED.

  1. find_toolsearches every tool by what you ask for
  2. describe_toolreads one tool's arguments
  3. run_toolruns any tool, or up to 25 in one round trip

Give a model the filings and the numbers change. With a Canli MCP server reading them, gpt-5-mini answered 72% of the FilingFacts questions correctly, against 19% on its own.

04The receipt

An answer you can trace to the page it came from.

Ask for NVIDIA's head count. canli-mcp opens the latest 10-K, finds the line and returns it with the filing's accession number, its link and a SHA-256 hash of each document it read.

Agents will research, test and trade at machine speed. Canli Capital is building what they stand on, in the open, in four parts.

Questions

Plain answers.

What is Canli Capital?

Canli Capital is an open-source lab that connects AI agents to financial data and quant tools they can check. It publishes MCP servers, company financials traced to SEC filings, open benchmarks and its own paper-trading record, failures included. See what stays open.

What is canli-mcp?

canli-mcp is one MCP server that loads every Canli Capital server in one process. The model sees three tools, find_tool, describe_tool and run_tool, and behind them sit 285 tools for quant finance, backtest validation, SEC filings, fundamentals, rates, prices and paper trading. See every server it combines.

How do I add canli-mcp to Claude, Cursor or another AI assistant?

In Claude Code, run claude mcp add canli -- npx -y canli-mcp. In Cursor, Claude Desktop or any other MCP client, add a server named canli whose command is npx with the arguments -y and canli-mcp. It needs Node.js 20.10 or later and no account. Follow the setup guide.

How does canli-mcp compare with OpenBB, EdgarTools and Yahoo Finance MCP?

With the same model and questions, canli-mcp answered 79% of the questions every server finished correctly, against 54% for the best of the others, and it sends the model 859 tokens of tools on every request. We wrote the questions, so read the caveats too. See every run and the caveats.

Where does the data come from?

From the original publishers: companies' filings with the SEC, the US Treasury's daily yield curves, FRED for economic series and Yahoo Finance chart data for prices. Answers drawn from data name their source, and answers from a filing carry its accession number. Browse the company pages.

How do I check whether my backtest is overfit?

Send the returns your backtest produced to the validators. The deflated Sharpe ratio corrects for how many variants you tried, the probability of backtest overfitting compares those variants with each other, and the minimum track record length says how much history the Sharpe ratio needs. Read the step-by-step guide.

Is it free?

Yes. The MCP servers and the code are free and MIT-licensed, the published data is CC BY 4.0, and the hosted API has fair-use limits. No paid plan is offered. Start with the developer quickstart.

Does my data leave my computer?

The quant and validation tools run on your machine and send nothing anywhere. The data tools fetch public data from the SEC, the Treasury, FRED, Yahoo Finance or canlicapital.com, and send only the company, series or symbol you asked for. See the setup and local mode.

Are your strategies trading real capital?

No. ALPHAC, Canli Capital's trading engine, runs its strategies on paper, and the record says so on every page. Paper results do not establish what real trading would return. Inspect the record and its basis.

Can I invest or copy the trades?

Canli Capital is a research project, not a fund or investment adviser. This site does not offer managed capital or copy-trading. Read the project's boundaries.
