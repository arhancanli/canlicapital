5. **r/algotrading**. Rule 1 (reddit.com/r/algotrading/about/rules, archived 2026-03-23): "Content marketing, product or service announcements, and affiliate links are prohibited... even if the content is free or educational." No fit here.
6. **r/quant**. Rule 3 (archived 2025-12-18) allows "self-promotion... to an extent if it is relevant to institutional quants," but warns that a brand-new account's first post being a plug "will be removed and you will be banned." One high-effort educational post from an established account, at most.
7. **QuantConnect forum** (quantconnect.com/forum, 526 pages of threads). Its code of conduct explicitly permits "posts which deliver immediate value... such as sharing a well performing algorithm with attribution," so a genuine answer to a real overfitting question is normal there.
8. **Alpaca community** (forum.alpaca.markets, plus a Slack kept current by staff as recently as August 29, 2026). Guidelines only ban spam or vandalism; sharing the API as a direct answer fits.
9. **MCP registries**. Official registry.modelcontextprotocol.io: `mcp-publisher init`, edit `server.json` under your own namespace, `login github`, `publish`; still explicitly "preview" today. Smithery (smithery.ai/new or `smithery mcp publish`) needs a public HTTPS server URL. Glama (glama.ai/mcp/servers, "Add MCP Server") indexes straight from a GitHub repo URL. None can be used until a real MCP server exists.

- **r/quant**: never from a new or unestablished account; their own rule says a first post that's a plug gets removed and the account banned.
- **Wharton, Diamond Challenge, Regeneron ISEF, Conrad Challenge**: closed to outside research submissions by design. No action.
- **Blue Ocean**: not a finance competition. Do not pitch it, and do not frame it as one on the site.
- **The MCP server and the VectorBT, Backtrader and freqtrade integrations named in the brief**: unverified as live public features as of today. Do not claim them as shipped in any pitch until confirmed; lead with the verified free API and evidence standard instead.

The product is disclosure and reproducibility, not a return number; naming a Sharpe ratio outside its paper-capital, no-forecast context reads as a track-record claim even unintended.
