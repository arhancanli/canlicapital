# Phase 4 — navigation, shared reading system and homepage clarity

Approved by the user on 9 September 2026. Phase 5 still requires permission. No deployment, real subscriptions, key issuance or trading changes.

## Design decision

Keep paper #f4f4f4, ink #111111, white #ffffff, cobalt #0016cb and copper #ff5500. Chakra Petch remains the expressive display face; Inter carries navigation and reading; IBM Plex Mono labels data. The signature remains the native mechanism studies and research-to-record sequence. Shared UI should frame those moments, not compete with them.

The current navbar mixes a changing broker-status width with several controls and hides the mobile CTA label. Replace that with a stable-height bar and readable action. Move the complete broker status into the full-width navigation disclosure. Group all current routes by visitor intent; retain source links. Native details provides a no-JS menu. Add Escape, outside click, focus-leave and link-close behavior without trapping Tab.
