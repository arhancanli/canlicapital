Approved 10 September 2026. Scope: /developers, /tools and the seven tools listed by build-tools-hub.mjs. ## Direction

Audience: developers and researchers checking their own work. Job: find the appropriate validator, understand its inputs and limitations, run it and inspect the result.

Palette: paper #f4f4f4, white #ffffff, ink #111111, cobalt #0016cb, muted ink #58616b, copper #ff5500 for accents only. Chakra Petch titles, Inter reading, IBM Plex Mono code/data. Keep dark calculator instruments where they aid chart reading; light reading surfaces elsewhere. Do not recolor verdict semantics into generic branding.

Two layout options considered: another image-led splash versus an instrument-led entry. Choose instrument-led: the real code workbench and source-bound calculator outputs are the signature. Remove the developer's abstract background treatment; give API onboarding and endpoint references deliberate hierarchy. The tools index becomes a scannable directory instead of repeated equal cards. Tools retain their distinct functional visualizations, with compact introductions and clearer input/result/interpretation separation.

Developer: introduction → local section index → existing quickstart → read/validation reference → quotas/limitations. Tools: compact purpose and basis → working instrument → interpretation → sources. Preserve every original link, control, figure, example and qualifier. New navigation is explicitly additive; do not reset the original preservation baseline. Record pre-existing evidence updates separately from this phase's edits.
