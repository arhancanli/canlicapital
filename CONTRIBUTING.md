# Contributing to Canli Capital

Contributions are welcome for accessibility, browser compatibility, performance, factual
corrections, reproducible evidence presentation, and documentation.

- Treat every performance figure as a sourced claim, not marketing copy.
- Preserve the paper-trading and no-investment-advice disclosures.
- Do not add credentials, account data, licensed data, or proprietary research inputs.
- Link quantitative corrections to the corresponding ALPHAC artifact or methodology.

Run `npm ci` and `npm run build` before opening a pull request. Explain any user-visible claim,
accessibility behavior, or glass-box artifact changed by the patch.
